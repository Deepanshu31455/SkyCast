# SkyCast — React + Vite Weather Application

A modern, responsive weather dashboard built with **React**, **Vite**, and **Lucide Icons**, powered by the OpenWeatherMap API.

---

## ✨ Features

- 🌍 **Global City Search & Geocoding**: Search for weather in any city worldwide.
- 📍 **One-Click Geolocation**: Get instant local weather using browser geolocation (`My Location`).
- 🌡️ **Unit Switcher**: Seamlessly toggle between Celsius (°C) and Fahrenheit (°F).
- 🕒 **24-Hour & 5-Day Forecasts**: Switch between detailed 3-hour interval timeline and daily summary forecasts.
- 💨 **Comprehensive Metrics**: Humidity, Wind speed & direction, Atmospheric pressure, Visibility, Cloud cover, Sunrise & Sunset.
- 🎨 **Dynamic Weather Themes**: Glassmorphic UI that adapts backgrounds and visual accents according to current conditions (Sunny, Clear Night, Clouds, Rain, Thunderstorm, Snow, Fog).
- 🕒 **Recent Searches & History**: Quickly jump between previously searched cities saved in `localStorage`.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Configuration
Create or inspect `.env` (a working default key is already pre-configured):
```env
VITE_OPENWEATHER_API_KEY=your_openweathermap_api_key_here
```

### 3. Start Development Server
```bash
npm run dev
```

### 4. Build for Production
```bash
npm run build
```

### 5. Preview Production Build
```bash
npm run preview
```
